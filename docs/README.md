# flowerss bot

> 一個支援應用內即時預覽的 Telegram RSS Bot。

## Features

- 常見的 RSS Bot 該有的功能；
- 支援 Telegram 應用內即時預覽；
- 支援為 Group 和 Channel 訂閱 RSS 訊息；
- 豐富的訂閱設定。
